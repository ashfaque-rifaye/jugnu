02How it is built

One web app, one API, a statistics engine and an AI layer. Every AI task has an offline fallback, so the demo never breaks.

Web appReact 19, Vite, Tailwind glass UI, framer-motion, three.js night map. Works on low-end Android; low-data mode.
APIOne Express app (server/app.ts). On Vercel it runs as a single function in Mumbai.
EngineStatistics in src/engine/: Find, Verify, Contrast, Spread, Track. Shared by browser and server.
AI layerClaude Haiku 5.5 through server/ai/run.ts, with guardrails and a logged trace of every call.
input ──► Claude (structured output, deadline) ──► guardrails (deterministic checks) ──► result
                │ no key · slow · declined · fails a check
                └──────────► offline engine (scripted interviewer, keyword coder, rules) ──► result
every call ──► ai_calls trace: task, model, time, tokens, cost, each check passed/failed

Where data lives

  • Demo block: 200 simulated schools calibrated to ASER 2024, with planted bright spots, inflated schools and decoy practices, so every step can be scored against the truth.
  • Live data: interviews, spot checks, visits and follow-ups go into SQLite locally, or Turso in production. Every open screen polls for changes (4 s active, 15 s idle).
  • Your block: import a CSV from Data & method and Find + Verify run on it.

04Using it, by role

Teachers never log in. Officers enter the console passcode once per browser.

Block Education Officer

/today
  1. Open the home page, choose I run a block, enter the passcode.
  2. The welcome takes 3 screens; accept the 1-minute guide.
  3. Today shows the one next step, the term rings and live activity.
  4. Walk the loop in the sidebar: Schools → Interviews → What works → Support plan → Results.
  5. Approve AI drafts (cards, voice notes) in Review.
  6. Ask anything with Ask Jugnu, e.g. "Which schools need help with reading?"

Cluster coordinator (CRP)

/today → role: CRP
  1. Pick your cluster in the role chooser.
  2. Open a candidate school; its tracker says what is due.
  3. Record the 15-child spot check on your phone in the field.
  4. Invite the teacher: QR, WhatsApp link, or a phone call.
  5. Arrange the peer visit and mark it done; it reaches the BEO's screen in seconds.

Teacher

/talk/<link> or a phone call
  1. Open the link on any Android phone; no app, no login.
  2. Hear the consent question in Hindi and answer by voice.
  3. About 12 minutes on daily routines; Jugnu asks follow-ups.
  4. On a basic phone the same interview arrives as a call.
  5. Later: a 60-second voice note from a nearby teacher, and a day-14 "did you try it?" call.

Judge or visitor

/ · /ai · /method
  1. Home page: the story of one practice, then Play the term.
  2. AI & guardrails (/ai): every Claude call, its checks and the evaluation.
  3. Data & method: the statistics and the CSV import.
  4. Testing: sessions, SUS scores and what changed.

07Real phone calls

Build stage: the phone line is a real outbound call — there is no simulator any more. Exotel is the live provider (Indian caller ID, trial account). Jugnu dials the teacher, the call's audio streams over a WebSocket to the API, Google Chirp hears the Hindi and speaks the next question, and every turn is stored like a web interview.

Exotel (live today)

  1. Settings already in .env: TELEPHONY_PROVIDER=exotel, API_KEY_EXOTEL, API_TOKEN_PASSWORD, EXOTEL_SID, EXOTEL_HOST, EXOTEL_FROM (the ExoPhone), EXOTEL_APP_ID (the flow), PUBLIC_URL, PHONE_SALT.
  2. One thing in the Exotel dashboard: open the flow named in EXOTEL_APP_ID → add a Voicebot applet → paste the WebSocket URL printed by GET /api/ivr/setup (it looks like wss://<PUBLIC_URL>/api/ivr/exotel/stream?key=…) → end with Hangup.
  3. Trial limits: calls go only to numbers verified on the account; business KYC lifts that.
  4. Where the API runs matters: the audio needs a long-lived WebSocket, so the API must run on a long-lived host or through a tunnel (cloudflared is used locally). Vercel functions cannot carry a call; the web app on Vercel can still point at such an API.
  5. Dial from the app: Interviews → Phone line → enter the number → Call. The call's status (dialing, in-call, completed, no answer) shows on the interview card.
